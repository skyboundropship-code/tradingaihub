## 2. Show HN

**Title:** Show HN: TradingAIHub – verified directory of finance/trading MCP servers and AI tools

**URL:** https://tradingaihub.com

**Text:**
```
I kept finding finance MCP servers and agent skills that were abandoned or unofficial wrappers posing as official. So I built a static directory that re-checks every entry weekly: last commit, archived status, official vs community. Right now it has 75 tools in 9 categories (market data, brokers, crypto, accounting, SEC filings, quant, macro...).

It's built with Astro on Cloudflare Pages, uses a Python verifier and the GitHub API, and pings IndexNow after each deploy. It's in 13 languages, and the list is also published as an awesome-list on GitHub.

Feedback welcome, especially on tools I'm missing or ones that are mislabeled.
```

Best time: Tue–Thu, 15:00–17:00 Israel time. Reply to every comment in the first 2 hours.
